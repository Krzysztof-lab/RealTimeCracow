# RealTimeCracow




## MCP – konfiguracja klienta


### Dostępne narzędzia (tools)
- `list_stops` – zwraca listę wszystkich przystanków GTFS
- `find_connections` – zwraca 3 najszybciej odjeżdżające połączenia bezpośrednie (uwzględnia opóźnienia)
- `next_departures` – zwraca 5 najbliższych kursów dla danego przystanku i linii (uwzględnia opóźnienia)
